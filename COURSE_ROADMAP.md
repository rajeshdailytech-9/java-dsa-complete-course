# 90-Day Roadmap

Each module lasts six days. Use the sixth day to consolidate patterns, revisit mistakes, and complete a mixed challenge.

| Module | Days | Outcome |
| --- | --- | --- |
| Java Foundations | 01–06 | Write clean Java and reason about runtime and memory |
| Problem-Solving Patterns | 07–12 | Trace, recurse, backtrack, and recognize common array patterns |
| Sorting and Searching | 13–18 | Choose and implement search/sort algorithms |
| Linked Lists | 19–24 | Manipulate nodes safely and recognize pointer patterns |
| Stacks and Queues | 25–30 | Use linear data structures and heaps appropriately |
| Hashing | 31–36 | Apply hash-based lookup, grouping, and prefix-sum patterns |
| Trees | 37–42 | Traverse, validate, and reason about binary trees |
| Advanced Trees | 43–48 | Solve trie, range-query, and top-K problems |
| Graphs | 49–56 | Model networks and apply graph algorithms |
| Dynamic Programming | 57–63 | Derive states, transitions, and optimized solutions |
| Greedy and Intervals | 64–69 | Make defensible local choices and schedule intervals |
| Strings | 70–75 | Solve matching, palindrome, and string-DP problems |
| Advanced Problem Solving | 76–81 | Combine specialized patterns for harder problems |
| Interview Preparation | 82–87 | Practice under constraints and publish a polished portfolio |
| Capstone and Next Steps | 88–90 | Curate a portfolio, assess progress, and plan the next cycle |

## Milestones

- **Day 12:** explain time/space complexity and solve baseline array patterns.
- **Day 30:** implement linked lists, stacks, queues, and a heap without copying code.
- **Day 48:** select suitable tree/range-query structures from problem constraints.
- **Day 63:** convert a recursive solution into memoized and tabulated DP.
- **Day 84:** combine graph, greedy, union-find, and backtracking patterns.
- **Day 90:** complete a mixed assessment and publish your retrospective.
