# Java DSA Complete Course

A structured, hands-on **90-day Java Data Structures and Algorithms course**. It takes you from Java foundations and complexity analysis through core DSA, advanced techniques, interview practice, and a final capstone.

## Start Here

1. Read the [course roadmap](COURSE_ROADMAP.md) and [Java tooling guide](docs/JAVA_TOOLING.md).
2. Complete one lesson folder per day in order.
3. Follow the [daily workflow](DAILY_WORKFLOW.md), then mark the lesson in the [progress tracker](PROGRESS_TRACKER.md).
4. Use the [contribution guide](CONTRIBUTING.md) when sharing solutions, notes, or corrections.

## Course Map

| Phase | Days | Focus |
| --- | --- | --- |
| Foundations | 1–12 | Java, complexity, and reusable solving patterns |
| Core DSA | 13–48 | Sorting, lists, stacks, queues, hashing, and trees |
| Graphs & DP | 49–63 | Traversals, shortest paths, and dynamic programming |
| Advanced Patterns | 64–81 | Greedy, strings, union-find, and backtracking |
| Interview & Capstone | 82–90 | Timed practice, portfolio work, and reflection |

## Lesson Folder Contract

Every lesson lives in `days/day-XX-topic/` and includes:

- `README.md` — outcomes, study plan, and completion checks.
- `notes.md` — editable written notes and revision prompts.
- `notes.pdf/README.md` — an explicit placeholder for the handwritten-style PDF that will be added once the lesson is complete.
- `examples/README.md` — Java implementation exercises and suggested package layout.
- `problems/README.md` — practice prompts and reflection format.
- `diagrams/README.md` — included only when a visual model improves the topic.

## Prerequisites

- Java 21 LTS (Java 17 works too)
- Git and a GitHub account
- IntelliJ IDEA Community Edition, VS Code, or Eclipse
- Comfort with basic algebra; no prior DSA experience required

## Progress

Use [PROGRESS_TRACKER.md](PROGRESS_TRACKER.md) as the single source of truth. The target pace is 60–120 focused minutes per day, six days per week with a catch-up or review day as needed.
