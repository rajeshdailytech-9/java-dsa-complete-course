# Practice Problems — Day 07

## Minimum Practice

- **Warm-up:** identify inputs, outputs, and constraints for a small dry runs, tracing, and test-case design task.
- **Core:** solve one standard problem using today's primary technique.
- **Stretch:** solve a variant with altered constraints or an optimization requirement.

## Solution Write-Up

For every attempt, capture:

1. Brute-force idea and its complexity.
2. Optimized approach and the key invariant.
3. Java-specific implementation choice.
4. Tests: empty, minimal, duplicate, and worst-case inputs.
5. One sentence on what you would do differently next time.
