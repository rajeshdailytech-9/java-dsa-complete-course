# Day 21: Circular linked lists

**Module:** Linked Lists  
**Target time:** 60–120 minutes

## Learning Outcomes

By the end of this lesson, you should be able to:

- explain the core idea behind **Circular linked lists** in your own words;
- implement a small Java example without copying a finished solution;
- identify relevant edge cases and state time and space complexity;
- solve at least two related practice problems.

## Study Plan

1. Read [notes.md](notes.md) and fill in the key ideas during study.
2. Work through the implementation prompts in [examples](examples/README.md).
3. Attempt the exercises in [problems](problems/README.md).
4. Add your handwritten-style lesson PDF when complete; see [notes.pdf](notes.pdf/README.md).
5. Use [diagrams](diagrams/README.md) to sketch the state changes before coding.
