# Contributing

Thank you for helping make the course clearer and more useful.

## GitHub Workflow

1. Start from an up-to-date default branch.
2. Create a focused branch, for example `docs/day-15-merge-sort-notes`.
3. Keep changes scoped to one lesson or improvement.
4. Add or update the relevant lesson README, notes, examples, and problem guidance.
5. Open a pull request explaining the learning goal, complexity claims, and validation completed.
6. Do not commit generated binaries or fake handwritten PDFs.

## YouTube Workflow

When publishing a lesson video:

1. Match the video title and description to its `days/day-XX-*/README.md` folder.
2. Link the exact lesson folder, not only the repository root.
3. Include prerequisites, expected duration, and the problems demonstrated.
4. Commit supporting code and written notes before publishing the video link.
5. Add the completed handwritten-style PDF only after it has been created for that lesson.

## Content Standards

- Prefer clear Java 17+ code and descriptive identifiers.
- State time and space complexity for each solution.
- Explain tradeoffs and edge cases, not only the happy path.
- Do not copy paid or copyrighted course material into this repository.
